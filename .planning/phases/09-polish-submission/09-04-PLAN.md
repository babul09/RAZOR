| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-09-04-01 | Tampering | operation status | medium | mitigate | Derive terminal state from controlled task outcomes, sanitize error text, and test every status transition. |
| T-09-04-02 | Information Disclosure | agent provenance/status | medium | mitigate | Expose provider/fallback labels and safe failure reasons only; exclude prompts, API keys, and payment credentials. |
| T-09-04-03 | Denial of Service | status polling | low | mitigate | Reuse bounded polling and existing API paths; stop polling on terminal states and provide retry instead of an uncontrolled loop. |

</threat_model>
