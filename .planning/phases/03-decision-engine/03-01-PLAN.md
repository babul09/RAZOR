<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| RecoveryModel output -> DecisionEngine | Model probabilities feed expected-net-recovery; must stay finite in [0,1]. |
| DecisionEngine -> PostgreSQL | AgentDecision/AuditLog/RecoveryCase writes cross into the DB; malformed input must not create partial rows. |
| State machine -> RecoveryCase.status | Deterministic transitions must not silently corrupt case state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | EV computation | medium | mitigate | Keep P*amount - cost in integer paise via integer truncation; test a hand-computed value. |
| T-03-02 | Information Disclosure | persisted decision logging | low | accept | Local dev DB only; no secrets in decision JSON. |
| T-03-03 | Tampering | state transitions | medium | mitigate | Deterministic transition table + ValueError on invalid transitions; every transition audited. |
| T-03-04 | Tampering | partial DB writes | medium | mitigate | Wrap persist in a single session transaction; commit only after all rows built. |
| T-03-SC | Tampering | dependency/runtime | high | mitigate | Use only declared deps (sqlalchemy, psycopg2-binary); no new installs. |
</threat_model>
