## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API -> PostgreSQL | Read queries over case/outcome data; no secrets. |
| API -> Redis | Analytics cache payloads cross the cache; treat as untrusted on read (parse defensively). |
| CaseDetail -> response | Full decision timeline exposed; local demo only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | Redis cache payload | low | mitigate | JSON-decode defensively on cache hit; fall back to DB on parse failure. |
| T-05-02 | Info Disclosure | case detail | low | accept | Open demo API; no auth by design (documented). |
| T-05-03 | DoS | heavy analytics query | medium | mitigate | Redis TTL bounds DB load (NFR-01). |
| T-05-SC | Tampering | dependency/runtime | high | mitigate | Use declared fastapi, uvicorn, redis, sqlalchemy; no new installs. |
</threat_model>
