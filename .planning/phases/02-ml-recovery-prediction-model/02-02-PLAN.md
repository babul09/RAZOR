## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Training CLI -> local filesystem | Generated model code and metadata are written to a local artifact path. |
| Joblib artifact -> RecoveryModel.load | Serialized Python objects are loaded into the process. |
| XGBoost/sklearn pipelines -> future strategy engine | Probability outputs cross into downstream expected-value calculations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-02-04 | Tampering | RecoveryModel.save/load | high | mitigate | Load only explicitly trusted local artifacts, require the versioned envelope and exact FEATURE_COLUMNS/strategy metadata, and reject malformed files. |
| T-02-05 | Denial of Service | training CLI | medium | mitigate | Keep training offline, bound event count to a positive integer, and expose deterministic seed/output arguments for reproducible runs. |
| T-02-06 | Tampering | model probability boundary | medium | mitigate | Use sklearn/XGBoost predict_proba, cast to float, and test finite [0, 1] values after reload for every required strategy. |
| T-02-SC | Tampering | Python dependency/runtime installation | high | mitigate | Use the already declared scikit-learn, xgboost, pandas, numpy, and pytest dependencies; do not add a new package install. |
</threat_model>
