<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| web -> API | Dashboard fetches backend data over HTTP; no auth (demo). |
| EventSource -> SSE endpoint | Live updates streamed; reconnection on error. |
| API failure -> mock | Fallback must not mask real errors silently. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering | SSE endpoint | low | mitigate | Streaming generator bounded + terminable; valid JSON only. |
| T-07-02 | Info Disclosure | open API | low | accept | Demo-only, no auth by design. |
| T-07-03 | DoS | SSE long-poll | low | mitigate | Cap stream length/rate. |
| T-07-SC | Tampering | dependency/runtime | medium | mitigate | Use only project deps; npm install is part of scaffold. |
</threat_model>
